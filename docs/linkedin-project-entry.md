# LinkedIn Project Entry

## Title
E-Commerce Operations & Customer Intelligence | Power BI + SQL + Python

## Description
Built a real-data e-commerce analytics case study using the Olist Brazilian E-Commerce Public Dataset. I combined a Data Analyst workflow - data quality, SQL, Python/Pandas, KPI engineering and business interpretation - with Power BI Analyst capabilities including semantic-model design, DAX, dashboard architecture, customer intelligence, logistics/customer experience, geography and QA.

Verified results include R$13.49M merchandise revenue across 98,199 sales-eligible orders and 94,983 unique customers, with a 3.04% observed repeat-customer rate, 93.23% on-time delivery and a 4.07/5 average review score.

The same governed real-data foundation supports six dashboard views: Executive Performance, Sales Explorer, Customer Intelligence, Logistics & Customer Experience, Geographic Performance, and Data Quality & Method.
